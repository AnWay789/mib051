# MIB 051 — приглашение и удостоверения агентов

Статический лендинг-приглашение в стиле «Люди в чёрном». Гость вводит имя, позывной и
загружает фото — браузер сам собирает удостоверение MIB и отправляет готовый PDF
письмом на указанный адрес.

- **Хостинг:** GitHub Pages (обычная статика, никакого билда)
- **PDF:** генерируется прямо в браузере гостя (canvas → jsPDF)
- **Отправка:** Google Apps Script через твой Gmail, письмо с PDF во вложении
- **Стоимость:** 0 ₽, подписки и сторонние сервисы не нужны
- **Бэкенду не нужны ключи в открытом коде:** токенов на странице нет

## Шаг 1. Бэкенд в Apps Script (10–15 минут)

1. Открой <https://script.google.com/> → **Новый проект**.
2. Слева у файла `Code.gs` вставь содержимое `apps-script/Code.gs`.
3. Вверху `CONFIG` замени:
   - `RECIPIENT_EMAIL` — **почта девушки** (кому уходят карточки);
   - `CC_EMAIL` — при желании свою почту, чтобы видеть, кто уже отчитался (иначе оставь пустым).
4. Шестерёнка **Project Settings** → включи **Show `appsscript.json` manifest file** →
   открой его и замени содержимое на `apps-script/appsscript.json`.
5. Выбери функцию `testSend` в выпадающем списке и нажми **Run**.
   Google попросит доступ: **Advanced → Go to (небезопасно) → Allow**.
   Это нормально — приложение твоё, оно просто просит право отправлять письма от твоего имени.
   На почту должно прийти тестовое письмо с вложением.
6. **Deploy → New deployment → Web app**:
   - *Execute as*: **Me**
   - *Who has access*: **Anyone**
7. Скопируй **URL веб-приложения** (заканчивается на `/exec`).

> Если вариант *Anyone* недоступен для твоего аккаунта — напиши, подберём обход.

## Шаг 2. Подключить лендинг к бэкенду

Открой `assets/app.js`, в самом верху:

```js
const CONFIG = {
  GAS_URL: 'ВСТАВЬ_СЮДА_URL_ВЕБ-ПРИЛОЖЕНИЯ',
  ...
```

Вставь скопированный `/exec`-URL. Ключ `SUBMIT_KEY` менять не обязательно, но он должен
совпадать в `app.js` и в `Code.gs` — это простая защита от левых запросов.

## Шаг 3. Проверить локально

```bash
cd MIB051
python3 -m http.server 8080
```

Открой <http://localhost:8080>, пройди терминал, заполни форму, загрузи фото,
нажми «ЗАРЕГИСТРИРОВАТЬСЯ» — письмо с PDF должно прийти на адрес из шага 1.

> Открывать `index.html` двойным щелчком тоже можно, но по `http://` надёжнее.

## Шаг 4. Выложить на GitHub Pages

```bash
cd MIB051
git init -b main
git add .
git commit -m "MIB 051 invitation"
git remote add origin git@github.com:AnWay789/mib051.git   # свой репозиторий
git push -u origin main
```

Дальше в репозитории: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
Через минуту лендинг будет на `https://anway789.github.io/mib051/`.

## Как это работает

```
гость                      браузер                     Apps Script              Gmail
  │                           │                             │                     │
  ├─ имя, позывной, фото ────►│                             │                     │
  │                           ├─ canvas → PDF               │                     │
  │                           │                             │                     │
  │                           ├─ POST в скрытый iframe ────►│                     │
  │                           │   (без CORS, обычная форма) │                     │
  │                           │                             ├─ письмо + вложение ►│
  │                           │                             │                     ├─► девушке
  │                           ◄── postMessage «sent» ───────┤                     │
  │◄─ «ACCESS GRANTED» ───────┤                             │                     │
```

Скрытая форма шлёт обычный POST в iframe — браузер не применяет CORS к навигации,
поэтому вся конструкция работает со статичного GitHub Pages. Ответ Apps Script
передаёт через `postMessage`, так что гость видит честное «отправлено», а не заглушку.

**Страховка:** кнопка «СКАЧАТЬ PDF» работает всегда. Даже если почта или скрипт
подведут, гость может отправить файл сам.

## Ограничения и риски

- **Квоты Gmail.** Обычный Gmail отправляет до 100 писем в сутки. Для 11 гостей с запасом.
- **Публичный URL.** Лендинг открыт по ссылке, в нём стоит `noindex`, но адрес в исходнике есть.
  Если это смущает — сделай имя репозитория неугадываемым или раздавай ссылку только лично.
- **Код бэкенда не коммить с реальным адресом.** В репозитории лежит версия с заглушкой;
  настоящий `RECIPIENT_EMAIL` держи только в редакторе Google.
- **Фото.** Ограничение 15 МБ, форматы JPG/PNG/WEBP. Фото нигде не хранится — оно живёт
  только внутри PDF в письме.
- **Спам.** Письмо уходит с твоего Gmail, поэтому в спам почти не попадает. Если уйдёт —
  попроси девушку пометить «не спам».
- **Устаревшие браузеры.** Динамическое добавление файла в `input` и `postMessage`
  требуют Safari 14+, Chrome 86+, Firefox 90+. Актуальные браузеры подходят.
